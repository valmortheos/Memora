Tips & Tutorial

Kembali ke App

Selamat datang di Memora! 📘

Memora adalah aplikasi catatan 100% client-side yang menggunakan sistem immutable commit. Setiap perubahan disimpan sebagai riwayat (seperti Git), dan dilindungi dengan kriptografi (Hash + HMAC).

1. Memulai (Passphrase)

Klik tombol Set Passphrase di pojok kanan atas. Passphrase ini berfungsi sebagai kunci untuk mengunci integritas file. Jangan lupa! Passphrase tidak disimpan di mana pun. Jika hilang, Anda tidak akan bisa memverifikasi atau membuka file .memento Anda.

2. Menulis & Format Teks

Gunakan tombol toolbar di atas editor atau ketik langsung sintaks berikut:

  • # Judul 1 (Heading 1)
  • ## Judul 2 (Heading 2)
  • **Teks Tebal** untuk Tebal
  • *Teks Miring* untuk Miring
  • `Kode` untuk Kode

Shortcut keyboard: Ctrl + B (Bold) dan Ctrl + I (Italic).

3. Menyisipkan Media (Gambar, Audio, Video)

Klik tombol 📎 Upload untuk mengunggah file baru. Kode media akan otomatis disisipkan ke dalam teks. Atau, ketik @ di awal baris untuk membuka Media Library dan menyisipkan file yang sudah pernah di-upload sebelumnya.

Media akan dirender sebagai kotak atau pemutar (jika audio/video) di dalam catatan.

4. Mengubah Ukuran Media (Resize)

Secara default, media akan tampil dengan ukuran normal (maksimal lebar layar). Anda bisa mengubah ukurannya dengan menambahkan parameter size=... di dalam kurung siku media.

Pilihan ukuran:

  • very-small (Sangat kecil, ~120px)
  • small (Kecil, ~250px)
  • large (Besar, 85% layar)
  • very-large (Penuh, 100% layar)

Contoh penulisan:

![[media:1ceb843b-8a32-4525-b683-1f849c1a6194]] (Normal)
![[media:1ceb843b-8a32-4525-b683-1f849c1a6194]size=small] (Kecil)
![[media:1ceb843b-8a32-4525-b683-1f849c1a6194]size=very-large] (Sangat Besar)

Catatan: Fitur resize hanya berpengaruh pada tampilan (CSS). File aslinya tetap disimpan dalam resolusi penuh dan memakan ruang penyimpanan yang sama.

5. Commit & Riwayat

Setiap kali Anda selesai menulis, klik tombol Commit (atau Ctrl + Enter). Ini akan membuat snapshot permanen dengan timestamp WIB. Anda bisa melihat riwayat di panel Commit History di bawah editor, melakukan Diff (membandingkan perubahan), atau me-Restore catatan ke versi sebelumnya.

6. Ekspor & Impor File (.memento)

Klik Unduh .memento (atau Ctrl + S) untuk menyimpan seluruh catatan, riwayat, dan media ke dalam satu file terenkripsi. File ini bisa Anda simpan di cloud atau flashdisk. Untuk membukanya kembali, klik Impor .memento.

7. Menghapus Media

Buka Media Library (tombol @), lalu klik ikon 🗑 (Tempat Sampah) di samping media. Menghapus media akan menulis ulang seluruh riwayat commit Anda agar media tersebut benar-benar hilang. Aplikasi akan meminta konfirmasi dan passphrase Anda.
